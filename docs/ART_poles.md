# Арт: опасные столбы = «электростолб» (одобрено Сергеем 26.10.2026)

**Правило (автоматическое, для всех текущих и будущих уровней):** любой блок шипов `"s"` с `h>14 && h>w*2`
(высокий узкий) рисуется как электростолб, а не как столб с шипами сверху. Отдельный тип блока НЕ нужен —
в уровне просто пишем `[x,y,w,h,"s"]`.

- Рисунок и смертельный хитбокс совпадают: ширина всегда `POLE_W=6` px. `poleR(r,L)` сужает блок при загрузке
  (и для физики `World.solids`, и для отрисовки кэша уровня). Если столб касается края поля (x≤0 или x+w≥fw) —
  прижимается к этому краю, иначе центрируется по исходному x+w/2.
- Значит, при дизайне уровня ширина столба в данных не важна (можно 6..30), важны центр/край и высота.
  Ставить столб ≥15 px высотой; низкие/широкие `"s"` остаются обычными шипами.
- Вид (стиль игры): контур 1px `#1a0c22`, диагональная жёлто-чёрная лента (#ffd93c/#3a3e48), свет слева,
  голубой изолятор из 2 рёбер сверху (#8af0ff/#e8ffff/#2aa0d0), целые пиксели, без AA.
- Анимация `poleFX()` — каждый кадр после `drawNight()` (не в кэше): спокойные искры-зигзаги ползут по столбу
  (~1 на 40 px высоты), искорка над колпаком. Ночью изолятор и искры светятся поверх ночи, лента видна на 30%.
- Искры — только эффект, не убивают (выступают за хитбокс на 1–5 px).
- После добавления столба: прогнать `fb/solve5.js` и `tools/lvcheck.js`.
