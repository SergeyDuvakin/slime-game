# Сейв ШМЯКОДРОМ: миграция v3 (100 уровней)

Ключ localStorage: `shmyak_v1` (не менялся, чтобы старые сейвы находились). Формат v3:
```
{ v:3, stars:[...100 значений 0..3], char:<индекс слизня>, mute:<bool>,
  legacy:<бонусные звёзды из старой версии>, open:<сколько уровней открыто без звёзд>, legacyFrom:<старая версия> }
```
Правила (`migrateSave` в game.js, выполняется при загрузке, если `v!==3`):
1. Старые звёзды привязаны к уровням старого набора (30 уровней) — на новые уровни их НЕ переносим (иначе на 100 новых уровнях появились бы «чужие» звёзды).
2. Сумма старых звёзд (каждое значение обрезается в 0..3, мусор = 0) переносится в `legacy`. `totalStars() = звёзды уровней + legacy`, поэтому все слизни, открытые за звёзды, остаются открытыми.
3. Прогресс: `open` = число старых уровней с ≥1 звездой → столько первых новых уровней сразу открыто (уровень i открыт, если i=0, i<open или на i-1 есть звезда).
4. `char` и `mute` сохраняются. Мигрированный сейв сразу записывается обратно (v:3), повторно миграция не выполняется.
5. Новый игрок (сейва нет) сразу получает v:3 без бонусов.

В меню показывается «★ N / 300» (звёзды уровней) и строка «+X ★ из старой версии», в выборе уровней — «всего» (с бонусом).
Тесты: tests.js — «v1 save migrated to v3», «old stars carried as bonus», «old progress kept», «migration persisted», «v3 save untouched», «v2 junk stars sanitized».
